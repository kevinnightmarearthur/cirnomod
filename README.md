# Cirno Goes Online (previously cirnomod)

Online co-op multiplayer mod for [Cirno! Lifts a Boulder](https://store.steampowered.com/app/4173110/Cirno_Lifts_a_Boulder/), played over Steam. Uses Godot 4.6's native `override.cfg` + `autoload_prepend`

## Features

- **Steam lobbies** - make a friends-only lobby or join a friend
- **See everyone** - other players show up as Cirno, with optional name tags and a nickname you can set
- **Everything is synced** - item pickups, frogs and ice platforms are synced between players
- **Chat** - press T (rebindable in the controls menu) to talk to your lobby
- **Settings** - nickname, name tags and other multiplayer options are in Gameplay

## Installation

1. Download `Cirno-Goes-Online` from the recent releases
2. Put what's inside the zip into where Cirno! Lifts a Boulder is.
3. You should see `override.cfg` and `cirno_goes_online/` next to `Cirno! Lifts a Boulder.exe`
4. Launch the game and the mod should be loaded.

Everyone in the lobby needs the same version of the mod. If yours is old you'll get a message when you try to join.

### Using it

1. You or your friend picks MULTIPLAYER and hosts a lobby
2. Other friends join through Steam (invite or the join option in the multiplayer menu)
3. Once in, press Play alongside everyone else.

### Uninstall

Delete `override.cfg` and the `cirno_goes_online/` folder from the game directory.
